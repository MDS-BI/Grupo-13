## Propósito del proyecto

Nuestro proyecto tiene como propósito diseñar e implementar un prototipo funcional del módulo de Ventas de un sistema ERP, orientado a facilitar la gestión de los procesos comerciales de una empresa. Buscamos que los usuarios puedan consultar listas de precios, elaborar cotizaciones, registrar pedidos de venta y gestionar devoluciones mediante una interfaz clara y fácil de utilizar, que permita organizar la información y dar seguimiento a cada operación.

Como equipo, queremos desarrollar un producto mínimo viable que represente las principales funciones del módulo y contemple su futura integración con otras áreas del ERP, como clientes, inventario y finanzas. Para ello, definiremos un modelo de datos coherente y utilizaremos una metodología de desarrollo basada en especificaciones. El resultado será un prototipo de interfaz que permita demostrar el flujo de ventas y establecer una base para futuras mejoras y ampliaciones.
